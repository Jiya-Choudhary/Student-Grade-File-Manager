# 🎓 Student Grade File Manager

A Python-based Student Grade File Manager that reads student scores from a CSV file, calculates grades automatically, and generates a new CSV report.

## ✨ Features

- 📂 Read Student Data from CSV
- 📝 Automatic Grade Calculation
- 💾 Generate Updated CSV Report
- ⚡ Fast & Simple Data Processing
- 📊 Student Performance Evaluation

---

## 🛠️ Tech Stack

- Python 3
- CSV Module
- File Handling

---

## 🚀 How to Run

```bash
python Grade.py
```

## 📌 Sample Input

```csv
Name,Score
Jiya,97
Ishika,50
Bhoomika,20
```

### Generated Output

```csv
Name,Score,Grade

Ishika,50,F
Bhoomika,20,F
```
